Logistic Regression
======

Logistic regression is a statistical method used for <b> binary classification </b> problems. Given a set of images, we wish to classify these as images of cats and not-cats. Using logistic regression, we design a model that predicts the probability that a given input image x has a cat. 

```
    P(y = "cat" | x) 
```
